# TRIDENT methods summary

TRIDENT separates productivity-model implementation from forcing-data uncertainty. The OSU replay workflow downloads archived MODIS-based CAFE input products, aligns mixed-resolution input fields to a common CHL reference grid, and runs the TRIDENT CAFE engine to compare against the archived OSU CAFE NPP product. NASA Earthdata and Copernicus production workflows are planned as modular data sources using the same grid-alignment and model interfaces.
